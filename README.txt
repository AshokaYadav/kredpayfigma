KredPay redesign - Figma import

How to open in Figma
1. Create a new Figma design file.
2. Drag all the .svg files into the canvas (or File > Import, or paste).
3. Each SVG becomes a frame with editable text layers, shapes, icons and images.

Files
00 Design System            colours, type scale, buttons, chips, field, PAID stamp
01 Home - Desktop           1440 wide, full page
02 Home - Mobile            390 wide, full page
03 Login - Desktop          1440 x 900
04 Dashboard Recharge       1440 wide, mobile recharge with a plan selected
05 Recharge Result - Mobile 390 x 844, success popup

Fonts
- Brand font is Anek Latin (Google Font, available in Figma).
- Screens 01-05 were exported with Inter so text positions match exactly.
  Select all text and switch the font to Anek Latin; use width 118 for big
  headlines (Display) and 100 for body text.

The PNG next to each SVG is a reference picture of how it should look.
The live website code is the source of truth for spacing and animation.
